The compiler now separates OpenAPI normalization (`compiler_openapi.py`), node/schema constructors (`compiler_nodes.py`), static checks (`compiler_checks.py`), and runtime source (`workflow_runtime.py`). `compile.py` retains assembly and dependency slicing, so unused runtime/calendar functions are still omitted from emitted stages. The redundant standalone opening smoke call was removed; the chat self-test already covers it.

Seven existing batch scripts now wrap one configurable runner (`scripts/run_batch.py`, `scripts/batches/*.json`). It resolves agent IDs from local slots, bounds waits and jobs, stops after failed publication, and preserves unique per-attempt evidence. The runner's dry-run preview was checked without launching simulations. Concurrently introduced batch scripts are outside this migration.

OpenAPI parsing resolves local references, accepts non-200 2xx JSON responses and path metadata, and explicitly rejects unsupported or ambiguous shapes before publication. README documents the supported subset, trace semantics, budgets, and pending-creation recovery.

## Remaining boundaries

The SDK exposes assistant messages, tool requests and session totals, not every provider-internal request/retry. Traces state this visibility limit rather than labeling a whole session as one model call. The source-isolation probes verified the real SDK permission hooks; they did not re-run a complete brief extraction or a full live conversation suite. The hard build deadline applies to local work; stopping a local simulation poller does not cancel a simulation already accepted by the remote platform. A pending creation with no visible remote match intentionally requires reconciliation before another creation attempt.
